# MatchConnect Promotional & Advertisement Website

Interactive advertisement and product showcase website for the **MatchConnect App**.

## Core Purpose

This website acts as the high-impact promotional landing page and interactive showcase for the **MatchConnect App**. It explains:
- **Why MatchConnect**: Solves the weekend amateur cricket chaos (endless WhatsApp texting, last-minute cancellations, double-booked grounds, lack of official umpires).
- **How MatchConnect Works**: 4-step journey (Connect 2 Teams in 48s &rarr; Book Floodlit Turfs &rarr; Assign Certified Umpires &rarr; Live Scoring & Tournaments).
- **Facilities for Users**: Dedicated features for Team Captains, Players, Turf Owners, Certified Umpires, and Tournament Organizers.
- **Interactive Advertisements & Video Reels**: 5 interactive simulated video showcases demonstrating fast team pairing, ground booking, umpire assignment, cash cup tournament brackets, and live scoring telemetry.
- **Interactive Demonstrations**:
  - 2-Team Matchmaking Simulator (see how two teams connect in seconds)
  - Interactive Cricket Scoring Telemetry Sandbox with boundary and confetti reactions
  - Verified Floodlit Turfs & Certified Umpires Directory

> [!NOTE]
> **All real actions** — connecting actual squads, locking turf slots with UPI payments, booking licensed panel umpires, organizing tournaments, and streaming ball-by-ball matches — are executed inside the **MatchConnect App** (`http://localhost:5173`).

## Running Locally

```bash
cd promotion-frontend
npm run dev
```

The site runs on **http://localhost:5175**.
